Math Gold Adventure

실행 방법
1. index.html 파일을 더블클릭하면 바로 실행됩니다.
2. GitHub 저장소에 index.html을 올리고 GitHub Pages를 켜면 웹사이트로 공개할 수 있습니다.

저장 방식
- 학교명 + 닉네임으로 로그인합니다.
- 같은 기기, 같은 브라우저에서 같은 학교명 + 닉네임을 입력하면 이어하기가 됩니다.
- 명예의 전당도 같은 기기 브라우저에 저장됩니다.
- 서버 저장 방식이 아니므로 다른 기기에서는 기록이 공유되지 않습니다.

포함 기능
- 직업 선택: 용사 / 광석 채굴자
- 수학 문제 풀이: 덧셈, 뺄셈, 곱셈, 나눗셈, 분수 비교
- 골드, 체력, 무기 강화, 레벨
- 약탈자 랜덤 이벤트
- 대장간 강화
- 잡화점 회복 물약
- 명예의 전당 랭킹
