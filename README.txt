Math Gold Adventure v2

실행 방법
1. index.html 파일을 더블클릭하면 바로 실행됩니다.
2. GitHub 저장소에 index.html을 올리고 GitHub Pages를 켜면 웹사이트로 공개할 수 있습니다.

이번 수정 내용
- 직업 선택 화면 삭제: 학교명과 닉네임 입력 후 바로 게임 시작/이어하기
- 몬스터 체력 시스템 추가: 정답을 맞히면 몬스터 체력이 1씩 줄어듭니다.
- 몬스터는 체력 3~4칸으로 등장하여 보통 3~4번 맞히면 퇴치됩니다.
- 약탈자 등장 빈도 감소: 몬스터 8~10마리를 퇴치한 뒤 랜덤하게 등장합니다.
- 약탈자 제한 시간 변경: 10초에서 20초로 늘렸습니다.
- 명예의 전당 유지: 같은 기기 브라우저 안에서 랭킹이 저장됩니다.

저장 방식
- 학교명 + 닉네임 기준으로 현재 기기의 브라우저 저장소(localStorage)에 저장됩니다.
- 서버 저장 방식이 아니므로 다른 기기와 기록은 공유되지 않습니다.
